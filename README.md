# Bobo's Fruit Race

A colorful racing game for kids! Collect fruits, avoid obstacles, and race to the finish line!

## Play the Game

**[Play Now](https://n2l3s4.github.io/hermes-game-2026-04-30/)**

## How to Play

- Swipe left/right or use arrow keys to change lanes
- Collect 15 fruits to win!
- Avoid rocks, puddles and traffic cones
- Or race 300 meters to the finish!

## Features

- Bright, colorful canvas graphics
- Web Audio API sound effects
- Touch and keyboard controls
- Particle effects on collection/crash
- Progress bar showing race distance
- "Good Game, Bobo!" celebration at the end

Built with HTML5 Canvas + vanilla JavaScript. No external dependencies!
